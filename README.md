# Referencias ECI — Catálogo Apple

Catálogo navegable generado a partir de `Ref ECI.xlsx` (26 hojas: iPhone, iPad, Mac, Apple Watch, AirPods, accesorios, EOL, etc.)

## Uso local

Abre `index.html` directamente en el navegador — no requiere servidor ni build.

## Publicado con GitHub Pages

Una vez publicado, la URL será:
`https://<tu-usuario>.github.io/<nombre-repo>/`

## Actualizar los datos

Si cambia el Excel de origen, regenera `index.html` y sustitúyelo en este repo.
